## Agent Review Desk 0.1.0 — first release

Record what AI coding agents (Claude Code, Codex) do on your machine, review the diffs and commands in a local web UI, approve or reject them, and pause risky actions until you decide. Local-first: JSONL + SQLite, nothing leaves your machine unless you ask.

> Early development. Install from source (not on npm yet). Behaviour and file formats may change between 0.x releases.

### What works

- **Record**: `ard init` (Claude Code), `ard init --agent codex`, or `ard run -- <agent>` for anything else.
- **Review**: `ard review` opens a local UI (127.0.0.1, per-launch token): timeline of commands and diffs, per-agent overview and filter, approve or reject a session.
- **Approvals** (opt-in): risky actions wait for your Allow or Block; a timeout is a denial.
- **Pull request gate without GitHub Actions**: `ard pr-status` and `ard pr-comment` with your own `gh`.
- **AI summary** (optional): your own Anthropic key, preview first, second click to send.

### Verified on real systems

Codex 0.169.0 blocking (shell, `apply_patch`, `codex exec`) and its fail-open timeout, a real pull request end to end, macOS Keychain.

### Known limitations

The policy is a safety net, not a sandbox. Redaction is best effort. macOS and Linux only. Not yet tried: picture data from Claude Code hooks. Full list: [README](../../README.md#known-limitations).

```bash
cd agent-review-desk && pnpm install && pnpm build
```
